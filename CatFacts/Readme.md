# 🐱 Random Cat Facts - Mini Project

This is a simple and fun web project that fetches random cat facts using an API. The project was built to practice **JavaScript Promises** and **API calls**, and styled using **HTML & CSS**.

---

## 📌 Features

- 🐾 Fetches a new random cat fact when you click the button
- 🎨 Clean and responsive UI with background image
- ⚡ Uses `async/await` for API call
- ✅ Simple and beginner-friendly project structure

---

## 💡 What I Learned

- Making API calls using `fetch()`
- Using `async` and `await` to handle Promises
- Manipulating the DOM in JavaScript
- Organizing HTML, CSS, and JS in separate files
- Basic styling and layout with CSS

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript (ES6+)
- [Cat Fact API](https://catfact.ninja/)


---

## 🚀 How to Use

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Click the **"Get Cat Fact"** button to get a random cat fact.
